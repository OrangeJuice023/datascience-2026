# SIGMA documentation index

Start here. SIGMA is a hackathon prototype. The only real data in the app is
the national OpenDengue weekly series. Everything else in the app is demo
data, and the dengue EARS / DOH-threshold pipeline runs offline. Each
document says which is which.
